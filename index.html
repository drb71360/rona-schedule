This page hosts an auto-updating iCal feed generated from the Legion WFM portal. The feed refreshes every 4 hours via GitHub Actions.

Subscribe

Copy the URL below and paste it into your calendar app:

Google Calendar

  1. Open Google Calendar → Other calendars → + From URL
  2. Paste the feed URL above and click Add calendar

Thunderbird / GNOME Calendar

  1. File → New → Calendar → On the Network
  2. Choose iCalendar (ICS) and paste the URL

Apple Calendar (iPhone / Mac)

  1. Settings → Calendar → Accounts → Add Account → Other
  2. Add Subscribed Calendar → paste the URL
